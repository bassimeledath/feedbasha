What happens after "switch to text" (all variants)

The mic never turns on. Cursor → crosshair, elements highlight on hover (react-grab style). Click an element → a composer pops beside it with Component · file:line and a note box. Type → Add → it lands in the same chronological log as voice. The live pill then shows a text-mode state instead of a timer.
